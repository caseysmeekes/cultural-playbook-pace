# The Cultural Playbook PACE

A starter web application for the Cultural Playbook PACE framework.

## Purpose

PACE helps users prepare for cross-cultural selling, negotiation and business interactions.

## Current prototype

- Country selector
- PACE profile for selected country
- Responsive mobile layout
- Next.js App Router foundation

## Roadmap

- Expand to all countries
- Integrate the Cultural Playbook source material
- Add sales and negotiation playbooks
- Add country comparison
- Add source/citation handling
- Add industry and interaction context
